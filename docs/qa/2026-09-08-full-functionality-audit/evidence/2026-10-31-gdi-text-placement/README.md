# Text set as GDI sets it: sector window, Game Options, main menu label

Date: 2026-10-31. Follows `../2026-10-31-gdi-font-sizes/`.

## What changed

`theme::paint_gdi_text` sets one line of text as `DrawTextA` does:
- **Size.** GDI's ppem (`original_font_ppem`, from Arial's VDMX).
- **Line.** The line's top comes from `DT_TOP` / `DT_VCENTER`, using GDI's
  `tmHeight`. The baseline is `tmAscent` below it
  (`original_font_metrics`).
- **Pens.** Each character sits at GDI's pen (`gdi_pen_positions`): Arial's
  advance at that ppem, plus the `kern` pair before the next character,
  rounded. A0 shows the pairs: "To" in "Tokmia", "Ya" in "Yavin".
- **Centring.** `DT_CENTER` uses the rectangle's spare width, halved in
  whole pixels.

The advances and pairs are generated by `tools/gdi-metrics/generate.py`
into `gdi_metrics.rs`, from Windows 10's Arial with FreeType's v35
interpreter. That interpreter's advances equal Arial's `hdmx` at every
ppem `hdmx` lists. Only the numbers are kept, not the fonts. The glyphs
are still Liberation Sans, in the egui cell nearest GDI's widths
(`gdi_font`).

Moved to it in this stage:
- **Sector window title.** Font 4, `DT_CENTER | DT_VCENTER` in a
  235-wide rectangle from (2, 2). A0's titles centre on x 119.5; the port
  had used 231.
- **Planet names.** Font 10, centred in the 100-wide box at the bitmap's
  x + 37 / 2 - 50.
- **Game Options texts.** In `draw_original_text`, the same metrics and
  pens through macroquad. The save name is in the default font (font 4,
  16-pixel cell): A0 `tooltip/200-options` shows "test" as 21 by 9, which
  is Arial at 13 ppem. The port had used font 10.
- **Main menu game-type label.** A0's "Standard Game" is 74 by 8, Arial
  at 11 ppem: font 10, not 8 as the port had it. The label's hand-tuned
  (-1, +1) offset is gone.

Gate changes:
- **`sector-windows.mjs`.** Each name: white, centre within 1.5 pixels,
  top and bottom within 1, width within 7 %.
- **`main-menu-rest.mjs`.**
  - Before: the left edge exact, the width only within a pixel. That
    exact left edge came from a hand offset on a label drawn 8 pixels too
    narrow.
  - Now: the width must be exact, and the left edge within 1 pixel.
  - Why the left edge moved: Liberation's side bearings round differently
    from Arial's hinted ones.
