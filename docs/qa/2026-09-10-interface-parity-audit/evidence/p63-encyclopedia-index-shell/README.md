# P63 Encyclopedia index-shell evidence

This folder contains the non-proprietary verification summary for the P63
Encyclopedia index-shell checkpoint.

- [`summary.json`](summary.json) records the exact source identity, fixture
  codes, browser/version hashes, comparison totals, diagnostics, and remaining
  acceptance boundary.
- [`browser-acceptance.json`](browser-acceptance.json) records the independent
  contact-sheet visual verdict and its explicit limits.
- Raw screenshots, source BMPs, console logs, and runtime packs remain in the
  ignored `.artifacts/interface-parity/` store and are not committed.

The parent [evidence report](../2026-09-28-encyclopedia-index-shell.md) explains
the source mapping and why `OBJ-01` remains open.
